# AI Meeting Task Dispatcher (n8n)

This workflow extracts action items and summaries from meeting transcripts and dispatches them automatically to each participant via Slack.

Flow:

Submit meeting transcript
→ AI extracts tasks and summary per person
→ Slack sends each team member their individual to-dos
→ Email sends the full meeting summary to participants
